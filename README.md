    CUSTOMER BEHAVIOR DATA ANALYTICS PROJECT

OVERVIEW
This project demonstrates an end-to-end data analytics workflow, covering data extraction, cleaning, analysis, visualization, and reporting. The objective was to transform raw data into meaningful insights using Python, PostgreSQL, and Power BI.

The goal of this project is to simulate a corporate-grade end-to-end data analytics workflow, demonstrating the ability to translate raw data into strategic business intelligence by:

✅ Data Preparation,Modeling & Exploratory Data Analysis (Python): Clean and transform the raw dataset for analysis.

✅ Data Analysis (SQL): Simulate business transactions, and run queries to extract insights on customer segments, loyalty, and purchase drivers.

✅ Visualization & Insights (Power BI): Build an interactive dashboard that highlights key patterns and trends, enabling stakeholders to make data-driven decisions.

✅ Report and Presentation: Write a clear project report summarizing your key findings and business recommendations. Prepare a presentation that visually communicates insights and actionable recommendations to stakeholders.

Project Workflow
1. Data Loading
  Imported the dataset into Python.
  Performed initial data inspection and validation.

2. Exploratory Data Analysis (EDA)
  Analyzed data structure and distributions.
  Identified trends, patterns, and outliers.
  Generated visualizations for key metrics.

3. Data Cleaning
  Handled missing values.
  Removed duplicates.
  Corrected data types and formatting issues.
  Prepared data for analysis.

4. SQL Analysis (PostgreSQL)
  Imported cleaned data into PostgreSQL.
  Executed SQL queries to answer business questions.
  Generated summary statistics and analytical insights.

5. Dashboard Development
  Built an interactive Power BI dashboard.
  Added KPIs, charts, filters, and trend analysis.
  Enabled data-driven decision-making through visual insights.

6. Reporting & Presentation
  Created a detailed analytical report.
  Developed a professional presentation using Gamma.
  Summarized key findings and recommendations.

How to Run
Prerequisites
  -Python 3.x
  -PostgreSQL
  -Power BI Desktop

Steps
-> Clone the repository:
  git clone <repository-link>
  
-> Install required Python packages:
  pip install -r requirements.txt

-> Run the Python analysis script:
  python main.py

-> Import the cleaned dataset into PostgreSQL.

-> Execute the SQL queries provided in the sql/ folder.

->Open the Power BI file (.pbix) to view the dashboard.
